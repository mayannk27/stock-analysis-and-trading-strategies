# Notebook inventory

The notebooks are numbered for convenient browsing, not to imply that all five form one sequential pipeline.

1. **PANW feature engineering and machine learning** — feature construction, feature selection and regression experiments.
2. **PANW exploration, LSTM and macro features** — exploratory analysis, LSTM and macroeconomic-data experiments.
3. **PANW Kalman, GARCH and trading strategies** — time-series modelling and trading-rule experiments.
4. **SQ Kalman trading experiment** — a separate Square/Block experiment.
5. **TSLA price distribution experiment** — a separate Tesla KDE experiment.

The PANW notebooks overlap in places but are retained separately to preserve the submitted research. Notebook outputs and execution counters have been cleared in this GitHub copy; code and markdown cells are retained. Some notebooks contain Google Colab-specific setup and file paths that may need adapting outside Colab.

Before using model results, review the repository's research limitations in the root `README.md`.
